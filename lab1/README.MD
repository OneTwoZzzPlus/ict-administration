# Лаба 1

> [!NOTE]
> После беззаботного времени на Windows просим GRUB запускать Ubuntu. Удивляемся, как удобно она была мной настроена. Синхронизируем vscode, музыку, браузер и конфигурацию Выхода Прямо в Нормальный инет (ВыПН). Донастраиваем ещё приколов, приближаясь к полной миграции с окон, и в бой.

Создаем директорию под лабу `/lab1`, внутри под приложение `/app` -- вынесем туда vibecode. Просим чатик поработать python fastapi джуном на полставочки. Получаем на выходе: `app.py`, `index.html`, `requirements.txt`, `Dockerfile`.

Команды докера давно забыты, поэтому сразу описываем, что хотим и `docker compose up --build`.

```yml
services:
    app:
        build: ./app
        container_name: lab1-app
        ports:
            - "8000:8000"
        restart: unless-stopped
```

Далее итерациями ругаем чатик за ошибки, вносим мелкие исправления по стилям. Производим фиксацию результата.

> [!WARNING]
> Репозиторий был создан на общем томе (ntfs). При попытке работы с репозиторием git заругался `fatal: detected dubious ownership in repository` (владелец файлов репозитория не совпадает с текущим пользователем) и сразу предложил решение `git config --global --add safe.directory` (считать безопасным работу в директории). Решение сработало.
