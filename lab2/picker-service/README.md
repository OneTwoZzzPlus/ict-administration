# picker-service

Читает топик Kafka **группой потребителей**, «собирает» каждый заказ (пауза) и
показывает на странице: партицию, offset и имя своего экземпляра.

- FastAPI + aiokafka. Страница `GET /` обновляется раз в секунду из `GET /api/state` (JSON).
- Консьюмер работает в фоне, при недоступности Kafka переподключается каждые 3 с.
- На странице видно, **какие партиции назначены** этому экземпляру (меняется при ребалансе).
- Коммит offset'ов — автоматический (по умолчанию в aiokafka, раз в 5 с).
- Обрабатывает по одному сообщению за раз, поэтому очередь копится быстро — удобно для наблюдения.

## Переменные окружения

| Переменная                | По умолчанию     | Что это                                        |
| ------------------------- | ---------------- | ---------------------------------------------- |
| `KAFKA_BOOTSTRAP_SERVERS` | `localhost:9092` | адрес Kafka                                    |
| `KAFKA_TOPIC`             | `orders`         | топик                                          |
| `KAFKA_GROUP_ID`          | `pickers`        | группа потребителей                            |
| `INSTANCE_NAME`           | `picker-1`       | имя экземпляра (у каждой реплики — своё!)      |
| `PICK_SECONDS`            | `2`              | сколько «собирается» один заказ                |
| `AUTO_OFFSET_RESET`       | `earliest`       | откуда читать, если у группы ещё нет offset'ов |

## Сборка и запуск

```bash
docker build -t picker-service .
docker run --rm -p 8001:8000 \
  --network <сеть-с-kafka> \
  -e INSTANCE_NAME=picker-1 \
  -e KAFKA_BOOTSTRAP_SERVERS=kafka:9092 \
  picker-service
```

Открыть: <http://localhost:8001>

Второй экземпляр — та же группа, другое имя и другой порт на хосте:

```bash
docker run --rm -p 8002:8000 \
  --network <сеть-с-kafka> \
  -e INSTANCE_NAME=picker-2 \
  -e KAFKA_BOOTSTRAP_SERVERS=kafka:9092 \
  picker-service
```

## Заметки

- Состояние обработанных заказов хранится в памяти (последние 50) — после рестарта страница пустая,
  но Kafka помнит offset группы.
- Для сброса offset'ов через Kafka UI группа должна быть неактивна — остановите сборщик перед reset.
