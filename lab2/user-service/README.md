# user-service

Страница с кнопкой «Создать заказ». По нажатию шлёт событие заказа в Kafka
и показывает, в какую **партицию** и с каким **offset** оно записалось.

- FastAPI + aiokafka, страница `GET /`, `POST /orders`, `GET /api/partitions` (список партиций топика, страница показывает его и обновляет раз в 2 с).
- Ключ сообщения = `order_id` → по ключу Kafka выбирает партицию (один ключ — одна партиция).
- Подключается к Kafka в фоне (повтор каждые 3 с, статус в логах). Страница открывается сразу, пока Kafka недоступна — `POST /orders` отвечает 503.
- Топик сервис **не создаёт** — он должен быть создан конфигурацией Kafka.

## Переменные окружения

| Переменная                | По умолчанию     | Что это                                                  |
| ------------------------- | ---------------- | -------------------------------------------------------- |
| `KAFKA_BOOTSTRAP_SERVERS` | `localhost:9092` | адрес Kafka                                              |
| `KAFKA_TOPIC`             | `orders`         | топик                                                    |
| `INSTANCE_NAME`           | `user-service-1` | имя экземпляра                                           |
| `METADATA_MAX_AGE_MS`     | `5000`           | как часто обновлять метаданные (замечать смену партиций) |

## Сборка и запуск

```bash
docker build -t user-service .
docker run --rm -p 8000:8000 \
  -e KAFKA_BOOTSTRAP_SERVERS=kafka:9092 \
  --network <сеть-с-kafka> user-service
```

Открыть: <http://localhost:8000>

Сообщение в Kafka: key = `order_id`, value = `{"order_id": "...", "items": [...]}`.
